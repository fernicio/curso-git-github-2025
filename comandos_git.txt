git init .	-> cria um repo git na pasta atual
git status	-> mostra o status do trabalho (de cada arquivo)
git add <nome_arquivo>	-> adiciona arquivo para ser comitado
git commit -m "msg"	-> faz o commit do que estava para ser comitado
git log		-> mostra todo o histório de commit

## FLUXO DE TRABALHO
1. criar o diretório do projeto
2. iniciar o git dentro do diretório de trabalho (git init .)
3. edita ou cria arquivos.
4. git status
5. git add <nome do arquivo> ou .
6. git status
7. git commit -m "mensagem"
8. git status
9. volta para o passo 3
